# Engineering & Systems Design Projects

## [Enterprise Network Architecture & Security](enterprise-network/README.md)
A simulated four-site Cisco Packet Tracer network. Includes enterprise topology (privacy-safe redraw), addressing/VLAN structure, STP/HSRP, PPP WAN connectivity, router/switch hardening, ACLs, NAT/PAT and verification evidence interpretation.

## [Student Management System — Systems Analysis & Design](student-management-system/README.md)
An academic systems design project covering stakeholder problems, requirements, five detailed use-case scenarios, UML activity/sequence models, proposed UI, project planning and cost/benefit reasoning.

### Evidence standard
Projects identify which parts were **configured/tested**, which were **designed and documented**, and which were **proposed for later implementation**. No original source report containing team identities or private records is included.
