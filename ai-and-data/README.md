# Artificial Intelligence, Python & Data Analytics

[Explore technical notes](artificial-intelligence/README.md) — programming, scientific Python, cleaning datasets and applying supervised learning.

## Technical learning areas
**Python engineering:** types, control flow, string manipulation, modular functions and collections.  
**Scientific computing:** NumPy dimensional arrays, vectorization, indexing and broadcasting.  
**Tabular data:** Pandas data inspection, filtering, modification and missing-value handling.  
**Visualization:** Matplotlib trends, comparisons, relationships and distributions.  
**Machine learning:** supervised/unsupervised learning, train/test split, KNN, logistic regression, SVM and classifier evaluation.
