# Portfolio Quality, Privacy and Evidence Standards

## Private infrastructure
Document the **work and skills** developed in the HomeLab without exposing its real network topology, live IP ranges, hostnames, server identity, private command endpoints, credentials, authentication secrets, configuration exports, private logs or identifiable screenshots.

Synthetic datasets can be discussed using sanitized documentation addresses or generic `source host` / `destination host` references. Do not publish the private deployment itself.

## Identity and academic privacy
Never commit student IDs, contributor/interviewee names, email addresses, phone numbers, signatures, meeting roster data, personal documents, API tokens or passwords. The original academic submissions are not uploaded. Technical configuration examples should be sanitized as appropriate.

## Evidence tiers
- **Implemented / tested:** directly supported by project outputs, relevant recorded tests or confirmed practical evidence.
- **Practiced:** a lab activity has been discussed or attempted, but the final outcome may need confirmation.
- **Studied:** concepts verified in lecture or course material, without implying a live implementation.
- **Planned:** not yet performed or independently verified.

## Approved imagery
- Practical screenshots: **Cisco networking, Huawei network security, Defence in Depth, Ethical Hacking** only.
- Artificial Intelligence: **text/code only**.
- Second-year project diagrams: only privacy-checked **redraws**, explicitly distinguished from screenshots of the original report.
- Do not upload private HomeLab screenshots.

Each accepted screenshot should be paired with the objective, command or action, observed result, what the evidence establishes, what it does not establish and any troubleshooting.

## Documentation style
Prioritize problem, architecture/technical rationale, methods, evidence, findings, limitations and learnings. Avoid course-code headings, daily diary entries, inflated claims or presenting an unverified design as a deployed service.
