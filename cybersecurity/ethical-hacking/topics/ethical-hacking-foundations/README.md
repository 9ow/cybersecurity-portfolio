# Ethical hacking foundations

The assessment process starts with authorization, then asset understanding, controlled discovery, evidence-based validation and clear remediation reporting.

[Detailed treatment of confidentiality, integrity, availability, authenticity, risk, adversary motives, assessment types, testing phases and rules of engagement](security-principles-and-engagements.md).

**Core distinction:** identifying a vulnerability is not the same as demonstrating access. Ethical intent does not replace written approval. Practical work should maintain system availability, preserve audit evidence and communicate uncertainty.
