# Ethical Hacking Foundations

## Information security foundations
The lecture defines information security as managing the risk of theft, tampering and service disruption. The **CIA triad** is confidentiality (prevent unauthorized disclosure), integrity (protect accurate/unaltered data) and availability (keep systems usable). **Authenticity** concerns genuine identity or origin and **non-repudiation** concerns credible accountability for an action.

## Understanding risk
An **asset** is something valuable; a **threat** could harm it; a **vulnerability** is an exploitable weakness; an **exploit** uses a weakness; an **attack vector** is a route through which exploitation could occur; **risk** depends on likelihood and impact. Security rarely eliminates every risk, so controls reduce it to tolerable levels.

## Threat sources and motives
Sources include insiders, cybercriminals, technical exploits, insecure applications, physical intrusion, environmental failures, supply-chain compromises and AI-specific attacks. Motivations can include financial theft, intelligence gathering, retaliation or ideology.

## Ethical hacking roles
White-hat testers operate with authorization. Black-hat actors work maliciously without consent. Gray-hat actors may lack malicious intent yet still test without permission. The lesson is that good intent does **not** replace written authorization. The lecture also introduces hacktivists, less-experienced tool users and state-backed operators.

## The five phases discussed
**Reconnaissance** gathers context; **scanning** identifies reachable systems and possible services; **gaining access** attempts exploitation; **maintaining access** describes persistence; **clearing tracks** attempts concealment. These are conceptual phases of attack methodology, not permission to carry them out.

## Ethical testing versus penetration testing
Ethical testing requires defined scope, written permission, rules of engagement and evidence-backed reporting. Penetration testing often has a narrower objective of safely demonstrating exploitability. Tools discussed include network mapping and vulnerability assessment utilities.
