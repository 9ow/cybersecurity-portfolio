# Huawei Enterprise Network Security

Notes and practical study topics covering Huawei VRP, enterprise routing and USG firewall technologies.

## Technical knowledge areas

- **[VRP Platform & Device Management](topics/vrp-platform-foundations/README.md)** — CLI views, system files, interfaces, VTY and configuration management.
- **[Network Models & Application Services](topics/network-protocols-and-services/README.md)** — TCP/IP layering, FTP modes, SFTP/STelnet, HTTP(S), DNS and device roles.
- **[Firewall Security Policies](topics/firewall-security-policies/README.md)** — Security zones, rule order, default-deny and stateful sessions.
- **[Huawei NAT Technologies](topics/network-address-translation/README.md)** — Source/destination NAT, Easy IP, NAPT, NAT Server and ALG.
- **[Firewall High Availability](topics/firewall-high-availability/README.md)** — VRRP, VGMP, HRP, heartbeat, synchronization and failover.
- **[Huawei Enterprise Security Learning Journal](HANDS_ON_LEARNING_JOURNAL.md)** — routing, firewall policies, NAT, authentication, high availability, IPsec VPN and troubleshooting.

## Focus

Developing hands-on skills in Huawei enterprise networking and security using eNSP and VRP.
