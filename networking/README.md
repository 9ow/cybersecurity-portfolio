# Networking & Network Security

Engineering knowledge organized by vendor and network problem.

## Cisco Networking
[Explore Cisco technologies](cisco/README.md) — network devices and cabling; OSI and TCP/IP; network administration and CLI; Ethernet switching, VLAN and trunk behavior. Practical enterprise design is documented separately as a [featured project](../projects/enterprise-network/README.md).

## Huawei Network Security
[Explore Huawei technologies](huawei/README.md) — VRP foundation and application protocols; stateful firewall policies; NAT translation methods; hot standby and availability. Detailed lecture examples and the verification register distinguish material studied from an actual executed lab.

## Core competency themes
- Addressing and packet forwarding: host addresses, networks, interfaces and route selection.
- Switching: MAC learning, broadcast boundaries, 802.1Q encapsulation and loop prevention.
- Network controls: ACL policy, trusted/untrusted zones and encrypted management.
- Reliability: redundant links, first-hop resilience, route failover and verification.

For hands-on work, record **topology, intended design, configuration, command output, failed tests and remediation**—not simply a successful ping.
